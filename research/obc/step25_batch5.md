## 一、X/462（10 例）——啟还是肇？

### 1. 字形比较（见 x462_sheet.png / x462_close.png）
比较行：X/462 全部 10 例；同族 X/461；HUST 肇 1290 / 肈 1291 / 肁 1292；啟 0362 / 啓 0363 / 启 0342；戶 0718 / 户 0719；攴 0741；取 0310；畋 1093。

### 2. 结构分析【未核：目验】
- **构件**：单扇门形（竖长框 + 中横，即「戶」）+ 手/动作旁（「又」或「攴」）。左右可互换（7444_1–3、7445_4、7446_1 户在左；7444_4、7445_1–3、7446_2 户在右）。
- **户旁**：与 HUST 戶 0718 / 户 0719 同型；框内一般只有一横，**没有**肇 1290 常见的内部繁笔，也**没有**啟 0362 部分例顶部的星/叉饰笔。
- **右旁判定是关键**：
  - 若为**裸「又」**（三指手）→ 按方稚松标准应归**啟**系。
  - 若为**「攴」**（持棍之手）或近戈 → 应归**肇**系，**不是**啟。
  - 目验：多数例右侧作一竖主笔 + 斜出分叉，**介于又/攴之间**；部分（如 7445_4、7446_1）更近又，部分竖笔上似有短横/斜贯，略近攴。**不能在不看原拓的情况下一刀切。**
- **与啟 0362/0363**：整体轮廓最近——户+手、左右可易位；分类器却只给啟 .04，与目验张力大。
- **与肇 1290/肈 1291**：肇类多从戈/攴，且左旁有时非标准户（盾/他形争议）；HUST 肇样本内部更繁。AI 肇 .78 可能被「户+打击旁」轮廓带偏。
- **与 X/461**：同为「框+又」族；461 框内更空或另有小方，clf 取 .45——同附录相邻，宜一并核辞例，但**不必先并为一字**。
- **与启 0342（户+口）**：0342 无手旁，是《说文》「启」一路；X/462 **有手旁**，不宜并入 0342。

### 3. 文献检索（本次实际打开）
- **方稚松《談談甲骨金文中的“肇”字》**，复旦网，https://fdgwz.org.cn/Web/Show/314 （本地 `gx/fang_zhao.html` / `.txt`，关键段 `gx/fang_zhao_qi_zhao_excerpt.txt`）。**已通读相关段落**：
  - 「啟」在甲骨文多作从戶从又（或加口、日、彳），以示用手开门；商周甲骨及西周金文中确定的「啟」**都从又，不从攴**；又→攴的讹变主要在更晚。
  - 金文「肇」异体：肈（户戈聿）、肇（户攴聿）、肁（户聿）、以及从户从戈/攴（或加口）而旧或误释为啟者——方文称之为「啓*」，强调**并非开启之啟**。
  - 甲骨 A/B/C（从戈或近戈/攴）应释肇之初文，用法有致送一类（花东、甲桥等）。
  - **对 X/462 的直接含义**【未核应用】：判别标准是**右旁又 vs 攴/戈**，不是「像不像开门」。团队口头「X/462→啟」只有在右旁确证为又时才成立。
- **日月《金文“肇”字補說》**，https://www.fdgwz.org.cn/Web/Show/1184 （检索摘要已读；未全文精读）。转引方说：肇主要从户从戈或攴，啟从户从又；从攴的𢼄/啟*是肇异体。
- **汉语多功能字库「啟」条**：https://humanum.arts.cuhk.edu.hk/Lexis/lexi-mf/search.php?word=%E5%95%9F （`gx/cuhk_啟.*`）。甲金文从𢻻（以手开门）从口；甲骨或省又作「启」；**西周金文从户从攴或戈之形是肇的初文**，参肇条。用法：禀告；又读晵（天晴）。
- **同库「肇」条**（`gx/cuhk_肇.*`）：金文从戈等；方稚松疑◎为盾；本义攻击/击打；《说文》肇，击也。
- **同库「戶」条**（`gx/cuhk_戶.*`）：半门象形；卜辞有「其启庭西户」一类。
- **袁校箋**：窗口无与本形对应的条。

### 4. 结论要点【未核】
1. **首选（条件式）**：若逐例右旁为「又」→ **啟之异体 / 正编漏收的又旁繁简**；与团队口头「→啟」一致，但须用原拓核右旁。
2. **次选**：若右旁为「攴/戈」→ **肇（啓*）系**，按方稚松**不得**释啟；AI 肇 .78 支持此路的可能性。
3. **排除**：即「启」(0342 户+口无又)；即畋/取（仅 MoCo/邻类噪音）。
4. 滞留附录的可能原因：啟/肇长期混释，刘钊对近形又/攴未并入正编啟或肇；或右旁不清。

### 5. 声符系列（第 5 步）
- **啟**（溪母脂部 / 上声荠韵康礼切一带）：啟、晵、棨、綮；卜辞又读晵（晴）。
- **肇 / 肈**（定母宵部一带）：肇、肈、旐；致送/始/击诸义通道（方文讨论致送；《说文》击也 / 始开）。
- 右旁未定前，**两系并行备查**，不要先绑一条谐声链到辞例上。

### 6. 待核
- **Loop Park 研究**：10 例原拓右旁是又还是攴；辞例是「启晴/禀告」还是「肇致送/军事」；与 X/461 是否同辞网络；原书附录 ~311 条。
- **Loop Master**：金文啟 vs 肇（方文第五类啓*）对照表；花东 B 字与本形是否同型。

## 二、X/956（18 例）——口/二覆丙

### 1. 字形比较（见 x956_sheet.png / x956_close.png）
比较行：X/956 全部 18 例；HUST 丙 0093；商 0358；尚 0579；高 1614；貞 1438；斝 0758；晶 0795；几 0224。

### 2. 结构分析【未核：目验】
- **下部／主体**：倒 U/V 外框 + 框内「八」或交叉斜笔，与 HUST **丙 0093** 高度同构（见 7917_1、7918_1、7919_2 等）。
- **上部区别性构件**：
  - 多数（7917–7918）顶上并列**两个小口/方框**；
  - 部分（7919 一带）简化为**两短横（二）**；
  - 少数顶作单长横或更繁叠画（7920_4、7921_2）。
- **与丙**：主体同；正编丙**一般无**上加双口。故更像**从丙之增繁/合体**，不宜在无辞例时径并入丙。
- **与商 0358**：商上部多为「辛」形尖顶/竖刺，下部丙形；X/956 上部是**口口/二**，**不是辛**——不能直接等同于商。
- **与尚 0579**：尚从八/小在冋/向上，HUST 样本少（3），轮廓与「口口覆丙」不同。
- **与高**：高为高台形，无丙内八。排除。

### 3. 文献检索（本次实际打开）
- **單育辰《釋（丙+止）》**，复旦网，https://fdgwz.org.cn/Web/Show/486 （`gx/shan_bingzhi.html`）。正文主释丙+止读「逢」。文末评论区 **陈剑**（2008-08-24）意见已读并摘录至 `gx/chenjian_dang_excerpt.txt`：
  - 主张相关诸形读「當」；
  - 「商」字本多不从口，所从「丙」形与独立天干「丙」未必有关，或为「尚」所从堂之初文「冂」之繁体（自云尚乏直接力证；参张亚初）。
  - **与 X/956**：提供「丙形 / 商 / 尚 / 冂」声系互相牵扯的背景；**并不直接考释「口覆丙」这一附录形**【未核应用】。
- **葛亮《古文字“丙”與古器物“房”》**，https://fdgwz.org.cn/Web/Show/4305 （`gx/ge_bing.html`）。**已读提要与本义论证要点**：丙象房俎之房的初文；用为天干是假借。有助于理解丙的物象形，**不直接说明上加口口的功能**。
- **汉语多功能字库「丙」条**（`gx/cuhk_丙.*`）：本义众说（鱼尾/底座/几）；甲骨「商」从丙；**楚系文字多加「口」作装饰**【战国现象，不宜直接套殷墟附录】；卜辞丙或读辆。
- **同库「商」「尚」条**（`gx/cuhk_商.*`、`cuhk_尚.*`）：商从丙从辛等说；尚与堂/冂/上同源线索。
- **袁校箋**：无窗口命中。

### 4. 结论要点【未核】
1. **首选**：从丙、上增「口口」或省作「二」的**未识合体/丙之繁形**；丙为声或义符待辞例。
2. **次选**：与商/尚声系相关的分化字（若陈剑「丙形≈冂繁体」一路可延伸）——目前缺辛旁、缺尚的八/小，证据弱。
3. **排除**：即正编丙（缺上部构件的解释）；即完整商（无辛）；即尚/高/貞/斝（轮廓不合）。
4. AI 丙/商/尚分数接近且都不高（.42/.38/.35），符合「像丙又多一层」的犹豫。

### 5. 声符系列（第 5 步）
- **丙**（帮母阳部）：丙、柄、炳、病、更（见系）；单文读逢则旁转东部（逢/丰）——仅作备选通道。
- **商 / 尚 / 賞 / 當**（若走陈剑评论的声系捆绑）：商章阳；尚禅阳；当端阳——与丙帮阳双声叠韵可通，但**本形是否入此链待证**。

### 6. 待核
- **Loop Park 研究**：18 例辞例（天干？人名？祭名？）；上口是刻意构件还是残渤/界划；原书附录 ~757。
- **Loop Master**：楚简加口丙与殷墟双口丙有无谱系；商省辛之形是否见于著录。

## 三、X/849（9 例）——祀还是示+卩？

### 1. 字形比较（见 x849_sheet.png / x849_close.png）

### 2. 结构分析【未核：目验】
- **左（或一侧）**：示旁——竖 + 上下横（T 形神主），与示 1162 / 祀 1163 左侧一致。7812_4 左右对调（卩/巳在左、示在右），符合祀「构形左右无别」（字库/国学大师材料常见描述）。
- **另一侧**：曲笔跪跽形——顶有闭合圆/椭圆头，身躯折曲；**介于巳与卩之间**：
  - 比典型「巳」(0609) 的螺旋胎形简单；
  - 比「卩」(0284) 多闭合头顶；
  - 7814_1 底部有环曲，更近巳。
- **与祀 1163**：HUST 祀正编从示从巳，巳旁头部常更圆转；X/849 右侧更「跪人化」。分类器/MoCo 双双首指祀（.34/.38），目验支持同系，但**右旁写法是附录未并的主要理由**。
- **与祝 1174**：祝为示+兄/跪人而头上有口或突出，X/849 **未见**清晰口旁，不宜径释祝。
- **与祼/祐/祏**：右旁各为灌器/又/石，不合。

### 3. 文献检索（本次实际打开）
- **汉语多功能字库「祀」条**：https://humanum.arts.cuhk.edu.hk/Lexis/lexi-mf/search.php?word=%E7%A5%80 （`gx/cuhk_祀.html`，摘录 `gx/cuhk_si_excerpt.txt`）。**已读形义通解**：
  - 甲金文从示、巳声；古已/巳一字；《说文》祀，祭无已也；或体禩从異。
  - 甲骨：纪年（唯王二祀，合 37836）；祭名（祀岳，合 9658）。
  - **未讨论**巳旁写成近卩的附录异体。
- **国学大师「祀」字形演变页**（检索摘要）：甲骨文本作巳，后加示；构形左右无别——**转引摘要**，未下载全部图版逐核对。
- **方稚松《談談甲骨文記事刻辭中“示”字的含義》**，https://www.fdgwz.org.cn/Web/Show/315 （检索到；本批未全文精读，仅作示/祀分用背景，不引具体结论）。
- **袁校箋**：无窗口命中。

### 4. 结论要点【未核】
1. **首选**：祀之异体（示+巳，巳作近卩曲笔）——与 AI、团队口头「→祀」一致，但仍标【未核】。
2. **次选**：从示从卩的未识祭名用字（若右旁证明不是巳声）——弱于首选。
3. **排除**：即祝（無口）；即祼；即单独示/主。
4. 说文古文「𥘅」是示之古文，**不是**示+卩的祭名专字；池注「祀或𥘅」的「𥘅」宜理解为示旁异写线索，**勿与 U+5615 古文示字头混淆**【未核：编码层面提醒】。

### 5. 声符系列（第 5 步）
- **巳 / 已 / 祀**（邪母之部）：祀、禩、汜、妃（部分）、改（己声近）；纪年义与「年/岁」通义不谐声。
- 若右旁实为卩不表声，则字或为会意祭名，声符另寻——目前无更好候选。

### 6. 待核
