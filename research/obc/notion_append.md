## 附加核查 B：WAIC 2024 甲骨文多模态数据集 = OBIMD
- 下载地址：https://huggingface.co/datasets/KLOBIP/OBIMD （doi 10.57967/hf/7828）。代码：https://github.com/libang1991/OBIMD 。论文：arXiv 2407.03900；Scientific Data（PMC13128845）。
- 协议：HF 卡片和 LICENSE 文件均为 CC BY 4.0。GitHub 仓库是 MIT，但 README 写“仅限学术研究，商用需许可”。期刊论文本身是 CC BY-NC-ND。按学术内部使用最稳妥。
- 本机可下载：HF API 非 gated，已实测下载。文件和大小：
  - `data.json` 41.7 MB（已下到 `/workspace/obimd/`）
  - rubbing.zip 558 MB
  - facsimile.zip 211 MB
  - 另有字头补充包
  - 合计约 0.85 GB
- 含片号：每条有 RubbingName，其中 H 开头（合集）9913 条、HD 开头（花东）164 条，共 10077；图片路径形如 `rubbing/h00002.jpg`。
- 兆序/兆辞单独分组：GroupCategory 分为以下几类，可直接用于批量检测“残字+兆序”误并：

  - OracleSequence(N)：兆序，3785 组 / 4597 字
  - OracleOutcome(N)：兆辞类，407 组 / 665 字
  - Uncertain：599 组
- 每字带 bbox（Position）、阅读顺序（OrderNumber）、占位标记（SeatFont），以及字头 UID（Label/SubLabel，需配合 Main-character.json 转成今字）。
