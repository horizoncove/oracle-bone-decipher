## 1. 释文与读序
- **OBIMD**：InscriptionSentence1 的读序 0–10 是 癸 丑 卜 王 貞 翌 甲 寅 王 其 賓，第 11、12 号是占位（残缺）。另有一个 **Uncertain 组**，含两个无标签字：#1 框 (110,53,61,98)，在“賓”左侧一行的顶端；#0 框 (154,227,58,88)，在左下。兆序组只有一个字“一”，框 (91,56,27,31)，位于 #1 的左上。
- **史语所词汇库**（以“甲寅王其賓”检索，唯一命中）：**合23248“癸丑卜王貞翌甲寅王其賓父丁必”**。
- 按读序，“賓”之后紧接的就是 OBIMD 的 Uncertain #1，**对应库释文中的“父”**。“丁”“必”在拓本上的位置：“必”很可能就是左下的 Uncertain #0；“丁”在残破处，或者是释文补出来的【未核，需看原拓】。

## 2. 连通性
- 连通性筛查（`obimd/zhaoxu_overlap_connected.csv`）：兆序框内墨迹的 shared_frac=1.0，也就是在摹本上“一”和 #1 的笔画完全连成一体。
- 拓本放大图（`img/h23248_zoom.png`）上也能看到，这一横从左上一直伸进 #1 的顶部，没有明显断开。这和队友看拓本的结论一致。

## 3. 两种读法测试
- **(a) 连同顶部横画算作一个字**：#1 会变成“父”形（手形 ⊃ 加杖的交叉笔画）再加一道左伸的长横。在小学堂“父”字头的 28 个字形中（覆盖賓、歷、午、何、無名、𠂤 各组）**没有这种写法**，我也想不出哪个已知字与之相当。按 (a) 读，“王其賓 X 丁必”中的 X 就成了不明的字。
- **(b) 去掉横画**：剩下的是“手形 ⊃ + 杖（斜笔）”，和小学堂“父”的写法相合（如合2128 賓、合22184 午、合32053 歷 等；本片手形在上，属于常见的变体，见 `img/xxt_fu.png`）。读作“**王其賓父丁必**”。
  - **同文例**：合23214.3“己亥卜行貞**父丁必**歲牡”（出组贞人“行”）；合32390.4“上甲史其祝父丁必”；合32654.4“祝于父丁必”；合32716“其侑父丁必惟今日戊”。
  - **同类句式**：合22779.2–.5“癸酉卜王貞翌甲戌王其賓大甲無”等，同是出组的“某日卜王貞，翌某日王其賓 某先王”。
  - “父丁必”（父丁的宗庙或神主之“必”）是现成的用语，所以 **(b) 读得通，而且有平行辞例**。
- **另一种可能 (c)**：这道横也许本来就是“父”字的杖，那么左上就没有兆序“一”，是 OBIMD 把“父”的笔画误标成了兆序。要排除 (c)，需要看这道横的最左端是不是一个独立的短横，即其左端是否位于卜兆的兆枝旁边【需看原拓或原骨照片】。

## 4. 兆序是否合理
本片残存的兆序只有这一个“一”，没有二、三等可以比较序列。“一”位于左上边缘，靠近骨边，在兆旁也说得通，但仅凭本片残片无法证实【无法判断】。

## 结论
- **字的归属**：#1 就是“父”。它不是新字，也不是误合出来的新字形。库释文“父丁必”和多个同文例都支持这一点。
- **刻痕**：是兆序“一”与“父”的顶部**相接或误连**（读法 b），还是 OBIMD 把“父”的一笔误标成兆序（读法 c），**二者待定**，需要看原拓或照片确认“一”是否独立。无论哪种，都**不影响释读**。
- **OBIMD 标注问题**：该字放在 Uncertain 组、没有标签，而库中已经释作“父”，属于漏标。这是“兆序误合”式风险的一个实例：旧释本身是对的，只是数据集的框和标签误导人。
