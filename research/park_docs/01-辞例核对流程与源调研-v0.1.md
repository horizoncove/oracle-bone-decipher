## 二、试点：《合》1098“仁”
1. 小学堂查字头“仁”（kaiOrder=78）：只收 **1 个字形**，标注 `前2.19.1 | 合1098 | 賓組`；字体图形是“人”旁加两横（见 `raw/ren_glyph.png`）。也就是说，旧字编（《甲骨文编》系）确实立了“仁”字头，而且只有这一例，属于孤例。
2. 史语所词汇库（限合集）全文查“仁” → **0 条**，说明合集释文里没有释作“仁”的字。查“羌”（1261 条）、“貞”（32938 条）都翻完了，**没有合1098 的记录**（只有 1094、1097、1099 等），所以没法从这里拿到 1098 的释文。可能的原因：这片没有收进库、整版残辞没有切分出来，或者用了占位码【未核】。
3. 文献依据：蒋玉斌在北大人文研究院的讲座（“甲骨所见文辞及人工痕迹的分层次动态观察”）纪要的例八说，早期工具书立了“仁”字头，复核原片《合》1098 后发现，所谓“仁”是命辞里残存的“羌”字下半和兆序“二”误合而成；例七提到《合》21473 的所谓“㐺”字是两个刻手刻的“从”和“人”的组合；例十提到《合》226正 的所谓“卌”字其实是兆枝上的废兆划线；例十三提到《合》15656 的疑难字其实是“燎于”缺刻横画（对照《合》14770）。（**来源：搜索引擎抓到的纪要摘要，原页在 box 上打不开，正式引用前要回原页核对。**）
4. **结论**：现有流程能**报警**（孤例、只在一种旧字编里出现、全文释文里查无此字），但不能**确证**。确证需要：(a) 看拓片或彩照，判断笔画是不是落在卜兆旁、是不是兆序的位置、和上面的残字能不能接上；(b) 同版、同文例比对。(a) 要靠殷契文渊登录或纸本《合集》，AI 这边必须有**看图能力**（可读 png/jpg），用户提供截图就能做。

## 三、单字核对流程（第1/3/4步）

### 0. 输入规范
候选ID（如 HUST X/2190）｜候选字形图｜拟释｜有没有片号｜来源字编及字头号。

### 第1步 真伪判定
1. **孤例检查**：小学堂、新甲骨文编、甲骨文字编里，这个字形各收了几例？出现几片？只有 1 片的，标“高风险”。
2. **构件对照**：字形能不能拆成 [已识字残画] + [数字一到十 / 二告 / 小告 / 不玄冥]？数字或兆辞构件落在一侧、笔势和主体不连贯的 → 怀疑误合（典型就是 合1098“仁”= 羌下半 + 二）。
3. **同文例对照**：在全文库里查同一句式（同干支、同贞人、同事类）。别的版这个位置是常见字的 → 怀疑缺刻（如 合15656 对 合14770）或改刻。
4. **刻痕层次**（要看图）：有无剜削、改刻叠压、废兆划线、残泐（如 合226正“卌”）。
5. 判定结果：**真未释 / 误合 / 缺刻 / 改刻叠压 / 残字 / 存疑**，并写明依据（片号 + 看的哪张图 + 文献）。

### 第3步 穷尽辞例
1. 跑 `tools/lexdb_fulltext.py`（限合集；需要时把屯南/英藏/花东/怀特/东大也勾上），检索项包括：拟释字、该字的**占位码**、**声符和可能的通假字**（例如 蠢 → 屯、春），因为库里可能把这个字放在别的字头下。
2. 对每条辞例：录片号、完整辞例，把候选读法代进去，按语法（主谓宾/祭名/地名/人名位置）判断能否读通；标出旧断读可疑的地方。
3. 小学堂里同一字头下列出的合集号，要和全文库的结果互相比对，找出漏收的。

### 第4步 类组互补
1. 把每条辞例的合集号，在小学堂里按字头 + 合集号过滤取类组；取不到的标“类组未知”，需查《甲骨文字编》或《合集材料来源表》。
2. 列 类组 × 字形 的分布表；同一套文例在不同类组用不同字形写 → 作为异体的强证据；只出现在一个类组 → 说明分布受限。

### 无片号的退路（HUST-OBC X/H 子集）
X = 《新甲骨文编》：用类别号回原书字头（附录号）→ 原书字形下有片号【需纸本或扫描件】。
H = HWOBC 手写摹本：没有片号，只能按字形反查。路径：拟释字或部件 → 小学堂字头（得到合集号）→ 全文库辞例；或者用户登录殷契文渊字形库，以形检字。
Y = 殷契文渊：用户登录后按字形编号回查。
任何一步只能从字形相似推测的，结论栏一律标“片号未核”。

## 四、输出模板（每个候选一份）
```
### 候选 <ID>  拟释：<字>   来源：<X/H/Y + 类别号>   片号：<有/无>
1 真伪判定：真未释 / 误合 / 缺刻 / 改刻 / 存疑
  依据：孤例? 构件分析; 同文例对照(片号); 是否看过图(来源); 文献(作者,篇名,出处,页码/URL; 未核标注)
3 辞例清单
| # | 片号 | 类组 | 完整辞例(原释文) | 候选代入 | 读通? | 备注(旧断读问题) |
4 类组分布与互补
| 类组 | 例数 | 字形特征 | 同文例对应字形 |
结论：读得通 / 存疑 / 排除 / 疑似异体 / 已释字匹配(非新释)；下一步需要(看图/登录/纸本)
```

## 五、主要卡点
1. 片号 → 拓片：公开渠道里没有；殷契文渊要用户登录，而且 box 访问它超时。
2. 词汇库没有类组，也不能按片号查；未释字用占位码，码表还没拿到。
3. 《甲骨文字编》《新甲骨文编》《诂林》《摹释总集》没有公开电子版，要纸本或用户提供扫描页。
4. HUST-OBC 没有片号元数据。

## 六、补充发现（做 02 时得到的）
- HUST-OBC **已释集**里 G 来源的文件名带有 旧著录 + 合集号 + 类组，例如 `G_1015_佚932合30792無名組.png`，内容和小学堂一致。**未释集**的 X、H 文件名里没有这些信息。
- HUST 的已释类 途、烄、求 里都没有 X 来源的文件，而对应的 X 未释类和这些字同形，说明有一批“未释 X 类”其实是映射漏洞。建议先做“X 未释 vs 已释同形”筛查，把这类假候选剔掉。
- 史语所词汇库可能**直接省掉无法编码的字**（屎、䧅 在对应片的释文里都查不到），所以库里查不到某字不能当作“无此辞例”的证据。另外，小学堂立为“求”的字，在库里写作“祟”。查候选字时要把声符、通假字、不同隶定都查一遍，例如 蠢→屯、春；求→祟、𠦪。
