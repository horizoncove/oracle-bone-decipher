# 10 HUST 附录类与小学堂“无新编页码”字头（主要是甲骨文编附录）的批量比对（v0.1，2026-10-02 中午，UTC+8）

## 方法
- **HUST 一侧**：`/workspace/obc/appendix_all_classes.csv` 里样本数 ≥3 的附录类共 131 个（按 serial 范围过滤），另加正编的 X/1370、X/1401。共 133 类、839 张图，用 MoCo 嵌入（`obimd/embed_q5.py` → `q5.pt`）。
- **小学堂一侧**：所有没有新编页码的字头，共 2927 个、4477 形（`raw/xxtapp/`，嵌入在 `obimd/xxtapp.pt`）。
  - 其中大部分是甲骨文编附录。少数有楷书，即甲骨文编正编里已经隶定、但小学堂缺新编页码的字头，例如 850“盾”、1066“兢”。
- **打分**：对每个类、每个字头，先对每个样本取它与该字头各字形的最高相似度，再对样本求平均。取最高的字头，margin 是它与第二名的分差。
- **结果表**：`obimd/appendix_to_xxtapp.csv`，133 行。列包括 top 字头、sim、margin、第二和第三名、该字头的字形数、片号和类组、目验结论，以及 plates_also_under_read_zitou（同一片号还出现在哪些已释字头下，只是“同版”，噪声大，仅供参考）。
- **目验**：按 margin 取前约 33 个，再加上优先类，逐一看了拼图（`img/a2x_1.png` 到 `a2x_6.png`，`obimd/app2xxt_sheet.py`）。
- **自检**：X/1189 → 3411、X/1190 → 3412（璞）、X/462 → 3670、X/833 → 3724，都与之前的结论一致，说明方法可靠。

## 优先类逐一说明
- **X/1212 → 4113（17 形），同形**。片号中有合6850、6848，正是 OBIMD 标签 jysk 所在的版（08 文档）。所以 X/1212＝史语所 Ｔ５４ 的结论得到加强。类组有 𠂤、𠂤賓間、賓、歷。
- **X/1370 → 3695（12 形），同形**：
  - 片号：合6313 賓、2976、19946 𠂤、4722 賓、19693 賓、27881 無名、20151、7065，以及前3.23.3、前5.34.1、後2.42.9。
  - 史语所库省掉了这个字：合19693.1“貞呼”，合7065甲.1“貞勿呼”，合6313.1“貞惟王征方”。从辞例看，它可能是“呼”的宾语，即人名【未核】。
  - 这是 06 文档以来第一次给 X/1370 找到片号。
- **X/276 → 4418（12 形），同形。这一条修正 06 文档**：
  - 4418 的片号：拾2.11、合14673 賓、33273 歷、14680、14653、14660、14650 賓、34282、14678、34276 歷、34271、34277。
  - 史语所对这些版的释文都写作 **Ｔ９**，是**接受燎、帝、求年的神名**。例如合14660“亥卜燎于Ｔ９二牛”，合1140正.8“方帝燎于Ｔ９卯上甲”，合10098“年于Ｔ９”，合34271“惟雨于Ｔ９”。全库 Ｔ９ 有 **102 条**（`raw/lex_Ｔ９.tsv`）。
  - X/276 的样本与 3775（合30442；~~06 文档里 Ｇ２８２ 的依据~~【作废：3775 应为 Ｂ４７６，未核】）的相似度只有 **−0.04**，与 4418 是 0.51。
  - 所以 HUST 的 X/276（7249–7251）应当是**神名 Ｔ９ 那个字**。06 文档把它定为人名 Ｇ２８２（依据 OBIMD a7al 在 H4479、H30442 上的切图），**需要降级为“形近的另一个字”**【需复核】。7252 是光，不变。
- **X/391 → 3151（23 形）；X/395 → 3148（7 形）；第二名都是 3150（9 形）**。这三个都是“凵上两竖”系列，即贞人 **Ｄ００６**（08、09 文档）。甲骨文编把它分成三个附录字头：3151 两长方，3148 两工形，3150。
- **X/833 → 3724，同形**（合10315 賓、10501、10503 𠂤賓間、10502、9572 賓），与 09 文档的 Ｈ０３１ 一致。

## 可能已经有释读的
- **字头带楷书的**：
  - **X/333 → 1066“兢”**（甲骨文编365.9；合17932 賓、40279、40825），同形。X/333 很可能就是甲骨文编所释的“兢”。
  - **X/1163 → 850“盾”**（29 形），同形或近似。
  - 这两类应当核对新甲骨文编为什么把它们放进附录。
- **字头带外字楷书的**（有隶定，但字不在 Unicode 里）：
  - X/113 → 4275，X/800 → 3848，X/1159 → 1250，X/1008 → 4104。
  - 这几个在甲骨文编或詁林中有隶定，只是我们无法显示（3848、4275 有詁林页码：3848 是詁林 2.1629、類纂中637；4275 是詁林 1.78、類纂上34）。
- **同版的字有没有被收在已释字头下**：对 32 个同形类，把它们所在片号在已释字头（有新编页码的）下的字形（254 形，`raw/xxtread/`、`obimd/xxtread.pt`）逐一与该类比相似度。**最高只有 0.37**（合6313 上的另一个字）。前 5 名目验都是不相干的字（`obimd/readflag.json`）。所以**没有发现同一个字被小学堂重复收进已释字头**。

## 局限
- 甲骨文编附录与新甲骨文编附录的分合不一致，所以“HUST 类 → 小学堂字头”可能是一对多，例如 X/82 和 X/391 系列。
- 小学堂每个字头最多显示 50 形，有截断。
- 目验只看了 72 像素的字形图，没有看拓片。
- 史语所释文里 X 被省掉的情况很多，辞位多数【未核】。
