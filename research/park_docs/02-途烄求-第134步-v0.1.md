# 候选 X/2190 途、X/1814 烄、X/2109 求（附 6000A 屎、X/2173 䧅）——第1/3/4步核对 v0.1
（Loop Park 研究，2026-10-02 约 10:10 UTC+8。不编造辞例、片号；凡未核者标【未核】。）

## 0. 数据与方法
- 候选来自 Notion《未释字候选样例 v0.1》。原始图片在 `/workspace/obc/data/HUST-OBC/undeciphered/`，候选和已释类的对照拼图在 `img/`（HUST-OBC 是 CC BY-NC，仅限内部使用）。
- **小学堂甲骨文**（底本《甲骨文编》）：`tools/xxt_summary.py 字`，返回字形数、旧著录、合集号、类组。原始 HTML 存 `raw/xxt_*.html`。
- **史语所先秦甲骨金文简牍词汇资料库**（只查《合集》）：`tools/lexdb_fulltext.py`，结果存 `raw/lex_*.tsv`。这个库不给类组；它的释文把小学堂“求”字头那种字形写成“祟”。另外，**库里不能编码的字可能直接被省掉**：小学堂收了 屎、䧅 字形的那些合集片，在库里对应的释文中都找不到这两个字。所以库里查不到某个字，不等于原辞里没有这个字。
- 合集“分期段”只是按《合集》编排的片号区间粗分（1–21525 一期，22537–26878 二期，26879–31968 三期，31969–35342 四期，35343–39476 五期）【区间凭记忆，未核】，**不等于类组**。真正的类组只取小学堂的标注。
- **重要旁证（HUST-OBC 自身）**：已释类 途(1477)、烄(1015)、求(0927) 里**一个 X 来源（《新甲骨文编》）的文件都没有**。整个已释集其实有 14519 个 X 文件，可见 X 来源一般是能对上已释类的。这说明《新甲骨文编》里这三个字的字形在建库时没对上已释类，被归进了“未释 X”。这是**标注/映射漏洞**，不是新字。（推测原因：新甲骨文编的字头隶定和 HUST 的字表写法不同，【未核】，需要查新甲骨文编原书确认。）

## 3. X/2109 → 求
**第1步**：39 个样本是一根长竖，两侧有向下的斜枝，顶端交叉（`img/X_2109_vs_0927.png`）。和 HUST 已释“求”(0927) 的一部分字形（竖笔加斜枝的那种写法）相近；0927 里另有一种顶端呈大“X”的写法，和候选差别较大。和“𠦪”(1696) 只是部分相似，𠦪 多是对称的枝杈加中竖（`img/X_2109_vs_1696.png`）。和“祟”(1175，上面像“木/屮”、下面是“示”的写法) 完全不同。样本多，不是孤例，**判为真字，归属存疑**（求 的可能性较大）。
**已释状态**：小学堂“求”字头（kaiOrder 633）收 **39 个字形**（解析到 38 个）。类组：**賓組 14、子組 2、出組 2、歷組 1、未标 19**。合集号：16962、16951、9273、1735、924、22324、24358、14521、17299、16975、16974、14720、7153、6057(×2)、2848、11503、24135、584、16955、32905、30419、367(×2)、4664、16935、17703、139、35592、21566。
**一个重要的对应关系**：用这些片号去查词汇库，对应位置的字一律写成“**祟**”，例如合6057“王曰有祟”、合32905“乙丑貞祟交”。也就是说，《甲骨文编》立为“求”的字，就是卜辞里常见的“有祟”的那个字；这个字的释读（祟／求／咎）学界有分歧【具体文献出处未核，此处不引】。

## 4. Y+H/6000A → 屎（标注一致性检查）
25 个样本（24 个 HWOBC 手写、1 个殷契文渊）是侧身人形，后下方有点，和已释“屎”(0590) **同形**（`img/Y+H_6000A_vs_0590.png`）。小学堂“屎”收 **6 个字形**：合9587反(賓)、9480(賓)、9584、9574(賓)、9582(賓)、31228(無名)。词汇库里这几片对应的释文**都没有“屎”字**（可能被省掉了，或者用了别的写法），所以库里拿不到辞例【需看殷契文渊或《摹释总集》】。
**结论：已释字匹配（屎），是数据集内的重复或来源间标注不一致，应剔除。**

## 5. X/2173 → 䧅（上级说的“久际”，Notion 表里的标签是“䧅”）
32 个样本是“阜”加右侧上下叠置的部件，和已释“䧅”(0073) **同形**（`img/X_2173_vs_0073.png`），分类器给了 32/32 票。小学堂“䧅”（kaiOrder 61898）收 **13 个字形**（解析到 11 个）：合1185、33981、5473、8963反、17586、10084、376、7067、6050、4775、5708；类组 **賓組 8、未标 3**（HUST G 文件另有 𠂤組 2）。词汇库里这些片的释文同样**查不到“䧅”**（可能被省掉了）。
**结论：已释字匹配（䧅），属于重复标注，应剔除。**“久际”的说法应改为“䧅”。
