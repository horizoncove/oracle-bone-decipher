# 06 附录/正编剩余候选复核：X/276、X/956、X/1370、X/1401（v0.1，2026-10-02 上午，UTC+8）

方法：用 HUST 图像的 MoCo 嵌入，去比对 OBIMD 5165 个未编码/未标注字的切图（`obimd/nn2.py`、`obimd/q2.pt`、`obimd/nn2.json`），再拿命中片号去汉达库查释文（`raw/lex_*.tsv`），并对照小学堂字形。
**注意**：OBIMD 里的 kwa7（一月）、lstx（十一月）、b1pj（十二月）、wo1c（八月）是月份合文，yhwc 是“子/㜽”。这些标签在相似度排序里经常出现，是噪声，不能当作命中。

## 1. X/276（序号 7249–7251）＝汉达库码 Ｇ２８２，人名；字形近“光”，但合集另立字头【释读存疑】
- **OBIMD**：最近邻是 H30442 上的 a7al7kr0c5（0.442），H4479 上同一标签排第 8（0.31）。这个标签全库只出现在这两版上。切图见 `img/obimd_04jj_ef1n_a7al.png`。
- **汉达库**：
  - 合4479.1：“壬辰卜惟Ｇ２８２令”
  - 合4480.1：“庚寅卜Ｇ２８２令Ｔ５４”
  - 用码 Ｇ２８２ 全库检索只有这 2 条（`raw/lex_Ｇ２８２.tsv`）。
  - Ｔ５４ 是侯名或地名，例如合3327.1“比Ｔ５４侯”、合4883.2“往于Ｔ５４”。
  - 合30442 用“王賓”“其遘雨”都查不到，所以库里这一版的释文【未核】。OBIMD 记为“□□卜[uw9w]□[X]□王賓□”。
- **辞位**：“惟X令”是“惟＋人名＋令”的句式，Ｇ２８２ 是人名。
- **在合集中的位置**：合集按人名排片，Ｇ２８１（合4477–4478）在前，**Ｇ２８２（合4479–4480）居中，“光”（合4481–4487：“光來”“光不其來”“光其貢”）紧接其后**；汉达库码也按合集顺序编号。可见合集编者认为它与“光”相近，但仍然**单列**，没有并入光。
- **字形**：上部是两歧（个别三歧）的火形，压在头上，下面是跪坐或站立的人。小学堂“光”的写法（合4481、4486、182、184）与此结构相同，只是光多为三歧火（`img/xxt_guang_qiang_ruo.png`）。“羌”是羊角向外弯，“若”是双手理发，都可以排除。
  - 注：这张图第二行误标为“光”，实际是羌，是脚本标签的 bug。
- **小学堂**：附录字號 3775 只收合30442 一形，无类组（`img/xxt_3775.png`）。
- **类组**：合4479/4480 都无贞人，类组【未核】。合30442 在合集里的编号区间属于第三期前后【按合集分期推测，未核类组】。
- **小结**：X/276 的 7249–7251 号＝Ｇ２８２（共 3 版：合4479、4480、30442）。很可能是“光”的异写，或从光的另一个人名，但**合集和汉达库都没有把它释为光**，所以存疑。
- **7252**：4 个字形，三歧火压在跪人上（`img/x7252.png`）。与 OBIMD“光”的 H182、H183、H4484、H7008 同形（`img/obimd_guang.png`），OBIMD 未编码字里也没有近邻（最高 0.28）。结论：**是“光”字，HUST 把它误放进了 X/276**。

## 2. X/1401 ＝ OBIMD 04jjwtizii（3 版），汉达库没有码（字被省略）；人名，可能是贞人【未释】
- **OBIMD**：
  - 最近邻 H1439（0.632），第二 H18204（0.549），第六 H3914（0.412），三版都是同一个未编码标签 04jj。
  - 字形：竖笔中间有横画，下部是三角，上部有分叉，与 HUST 图像高度一致（`img/hust_1370_1401_276.png`，`img/obimd_04jj_ef1n_a7al.png`）。
- **各版辞例（OBIMD／汉达库）**：
  - H1439：“甲申卜亘貞[X]禱于大甲”。汉达库合1439 作“甲申卜貞于大甲”，**亘、X、禱三个字都被省掉**。
  - H18204：“癸卯卜貞[X]□于□”。汉达库作“癸卯卜貞于”。
  - H3914：“□[X]貞□”。汉达库只有“貞”。这里 X 处在**“卜X貞”的贞人位置**。
- **辞位**：在 1439 和 18204 上，X 是祭祀动词（禱）的主语，即施祭者。在 3914 上处于贞人位。有贞人亘，可定为**宾组**。
- 这是**人名**（施祭者，或兼作贞人），但目前只有 3 例，贞人一说【待查拓片】。
- 汉达库不给这个字编码，所以用库**无法补出其他辞例**。小学堂在相应页窗里也没有候选字头（见 03 文档）。
- **结论**：已确认在 OBIMD 中出现 3 版，辞例有了，**字仍未释**。

## 3. X/1370：没有可靠命中【存疑】
- **字形**：上部是丅/示形（横画两侧带点），下部是一个横置的目形（或冎形），中间有三角（`img/hust_1370_1401_276.png`）。
- **OBIMD 命中都不可靠**：
  - 最近邻 H32994 的 ef1nwshoqj（0.49），这个标签在 OBIMD 里转写为“小臣”合文（汉达库合629“鬳小臣三十”，合12“惟小臣令眾黍”）。小臣是三点加竖目，结构不同，**排除**。
  - 其余命中都在 0.43 以下，而且多是月份合文或“子”等噪声。
- **“視”的假设（示＋目）**：只是字形上的推想，OBIMD 和汉达库都没有能落实的辞例【未证】。

## 4. X/956：上部是两个口，下部是“丙”形【未释】
- **字形**：下部是冂里面加八或入，与小学堂“丙”（字號 1677）一致（`img/xxt_956cand.png`）。上部是两个小方口（`img/hust_956.png`）。
- **OBIMD**：最高 0.51，命中都是月份合文（一月、十一月、十二月），等于没有命中。
- **小学堂**：“商”（268、798）上部是辛形而不是双口，**排除**。“丙”本身没有双口。附录没有新编页码，按楷书检字也找不到“吅＋丙”结构的字头。
- 结论：未释，需要逐页翻检甲骨文编附录或新甲骨文编附录的原书。
