# 存疑待释出处的线索类型

不写具体书名和页码。具体用哪一部、哪一页，一律待确认。著录号体系统一到《合集》、屯南或其他体系，也待确认。

可以当作线索来源的类型：

1. 大型字编或字典里的待考、未识附录。
2. 辞书类著作里的存疑、未释字条，以及该书凡例。
3. 学界综述。要注意年份：旧综述里的未释字，后来可能已经有人释出。
4. 专题研究，按组类或按主题。
5. 网络集释。只作线索，不作出处。出处仍须落到字编或论著。

登记里的 `source_citation` 必须能对应到第 1 或第 2 类那种“明确列为存疑/未识”的记载。只有网络集释、没有书证，校验不把 citation 视为合格。

## English

This page lists kinds of sources only. It names no book and no page. A web compilation can be a clue, not a citation.
