# 评审流程

本流程用自动校验、公开规则和固定模板。不设需要某一个人拍板才能往下走的步骤。“专家认可”这个名字保留，但暂空置，待有专业评审者加入后启用。什么样的人算“满足条件的评审者”，认定机制后续再定。在此之前，专家人数按不足 2 人处理，提案停在“可接受的候选”或更低，不能写成“专家认可”。

## 档位

未释字分档 `status_tier`，第一批校验只放行前两档：

- `widely_undeciphered`：学界普遍承认未释
- `multiple_no_consensus`：有多家释读但无共识
- `conventional_but_disputed`：已有通行释读但仍有异议（第一批不放行）

流程状态 `review_status` 只用：待议、有争议、可接受的候选、专家认可。不用“已破译”“已确认”“已有定论”。

“可接受的候选”是程序性合格，页面必须写这句固定标注：

> 未经专家评审，仅表示证据齐备、尚无已知反例

进入这一档要同时满足：

1. 形式门通过。`attestation_count`、`damage_level`、`all_attestations_read` 由复核者对照著录号锁定。提案人自己填的值不生效。
2. 至少 2 名互不相关的社区复核者独立确认引用可查，且通读无遗漏。提案人的合作者和关联账号回避。
3. 14 天反证期内没有未回应的实质反例。

反例若由两名独立复核者（不是提案人，也不是反例提交人）确认成立，状态退回“有争议”，记录保留，修订后重开一轮。

辞例数小于等于 2，或存在重残（`severe`），状态上限仍是“可接受的候选”。这个上限是经验设定，待校准。它不把提案自动抬到该档。

社区票只决定排队优先级，不能把“有争议”改成“认可”，也不能改任何状态。投票资格的自动判定还没做，见路线图。规则先写明：有已合并贡献的 GitHub 账号一人一票，新号只能评论。这只能挡住低成本刷票。

## 反证期

形式门和两名复核者确认之后，给 Issue 加上 `ready-for-counterevidence`。工作流 `.github/workflows/counterevidence.yml` 会加上 `counter-evidence-open`，并写明 UTC 起止日期。

- 窗口 14 天（UTC）。这是经验设定，待校准。
- 窗口内提案正文冻结。修改正文会按编辑时间重新计时。
- 反例用 [评论模板](templates/counterexample.md)。四项缺一，标“未成形”，不计入。
- 实质反例只有三类：代入真实辞例读不通；字形、辞例或分期组类与著录原书不符；此释读早有人提出且已有被驳回的理由。最后一类必须有可查原文和页码。
- 提案人在 7 天内逐条回应：接受、部分接受，或不接受并给出带出处的理由。7 天也是经验设定，待校准。逾期视为未回应，不得进入“可接受的候选”。
- 同一账号对同一提案最多 3 条未成形反例。
- 两名复核者都判定不成立的反例，计入该账号的不成立次数。累计 5 次，暂停提交反例资格 30 天，可以申诉。判定公开并附理由。5 次和 30 天是经验设定，待校准。

## 复核者资格

先有 3 条后来核对一致的辞例录入，才能做社区复核。3 是经验设定，待校准。脚本可以算出一致率，但页面必须写明：一致率不是准确率，也不用于排名或奖励。它只用于这个资格。

双人录入在提交时不应互相参照。公开 git 做不到密码学意义上的隐藏，所以两份要分开发送，不要打开对方的文件。归一化后不完全相同就是冲突，不自动合并，交给没看过前两份的第三名复核者对照原书裁定，裁定和理由公开。两人同错而一致，脚本查不出，需要抽查原书。高度一致是否串通，只在路线图里作为人工抽查，不自动处罚。

## 向机构提交

论证报告是公益行为，不收费。提交对象以中国文字博物馆为主。该馆公开网站是 <https://www.wzbwg.com/>，这不是投递渠道。具体投递方式待补充。本页不写电话、邮箱或个人。

在“专家认可”仍空置时，不发送报告。将来若要启用该档，必须先用公开的规则变更把 `registry/policy.json` 里的 `expert_endorsement_enabled` 设为 true，并在同一变更里写明认定机制。启用之后，报告还要满足：至少两名评审者署名、反证期结束且没有未回应的实质反例、证据包可复现、AI 只作为线索并标明、版权已核实。模板见 [report-template.md](report-template.md)。

## English

“Expert endorsed” is a reserved name and is vacant. “Acceptable candidate” means the file is procedurally complete and no live counterexample remains. It is not an expert verdict. Votes do not change status. The museum’s public website is not a submission channel; the delivery method is still unconfirmed.
