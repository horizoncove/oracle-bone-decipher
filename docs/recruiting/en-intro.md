# A short note for new contributors

This project openly organizes materials on oracle-bone graphs that specialists still treat as undeciphered. It does not promise to decipher them.

We need checking and data entry, not verdicts. Three ways to start: enter an inscription context, summarize a published discussion with page numbers and without judging it, or search whether a so-called new reading was made before. The first-task page is [docs/first-tasks.md](../first-tasks.md).

A note becomes an “acceptable candidate” only after the public rules and a counter-evidence period. That is not an expert review. Model similarity is not evidence. The same graph can have more than one use, so shape alone is not enough.

The work is a non-commercial public effort: no fees, no commercial operation, and maintainers do not profit from it. Code is MIT. Contributed readings are CC BY 4.0. Those licenses still allow reuse on their own terms.
