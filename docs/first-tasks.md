# 新手第一任务

示例都是虚构的。看到“示例数据，非真实释读”就不要当成真实著录。甲骨文有一形多用，只比字形不够，要先看用法。

## 1. 能做与不能做

能做：

- 辞例录入和核对
- 文献梳理：只归纳，不判断，必须写原书页码
- 异体整理：只能标“疑似同字”
- 检索和查重：看某个“新释读”是不是早已有人说过

不能由新手单独做：

- 字形归并的终判
- 残辞补缺和断句
- 分期分组的判定
- 任何写成“已有定论”“已破译”“已确认”的修改

禁止的论证见 [证据清单](evidence-checklist.md)：只凭字形或 AI 相似度、单条灵感、无著录号、改字迎合、不可证伪、玄学。

## 2. 十分钟示范

虚构编号 `OBD-000001` 已在仓库里，标明示例数据，非真实释读。它的图像指针是“待查原书”，著录是“示例字编EX-1”，不是哪一部真书。

你可以打开 `registry/dual-entries/EX-000001/`，看两个人各自写了 `丁未`。这只说明双录格式，不是卜辞。

不要把 `pilot/_drill/OBD-900001.md` 算成研究成果。那是演练号。

## 3. 三选一

| 任务 | 难度 | 耗时 |
| --- | --- | --- |
| 辞例录入 | 低。照模板抄自己的隶定，不上传图 | 大约 30 分钟学会模板，单条视材料而定 |
| 文献梳理 | 中。只归纳原文，每条都要页码 | 一篇短文大约 1 小时 |
| 查重 | 中。找别人是否提过同样的说法，记下出处和页码 | 一条线索大约 1 小时 |

耗时是经验感觉，不是承诺。

## 4. 双人独立录入

同一条辞例由两人各写一份。提交时不要打开对方的文件。公开仓库无法真正隐藏已合并的文件，所以请分两次提交。

归一化后完全相同才算一致。字段或符号不同就列为冲突，不自动合并。第三名没看过前两份的复核者对照原书裁定，理由公开。两人一起抄错时，一致也查不出，还要抽查原书。

## 5. 怎样核对

复核者对照著录号看引用是否找得到、辞例是否漏了。通过复核的条数用来计算一致率。页面上的一致率不是准确率，也不做排名、不发奖励。它只决定你能不能取得复核者资格：先有 3 条后来核对一致的录入。3 是经验设定，待校准。

## 6. 行为准则

遵守 [行为准则](../CODE_OF_CONDUCT.md)。不刷屏，不围攻，不把未复核的说法说成定论。

## 7. 版权

不上传图像，不裁切图，不复制未授权的书页或释文。著录释文能不能录入，版权待确认。没有 Unicode 的字先领号，再写成 `〔OBD-######〕`。

## 8. 提问

维护者在 GitHub 仓库的 Settings → General → Features 里打开 Discussions 之后，提问放到 Discussions，不要把讨论写成重复的 Issue。本仓库不假定 Discussions 已经打开，也不指向任何外部社群。

领号用 Issue 模板“申请字头编号”。测试编号不会发出来。

## English

### 1. What you may do

Enter and check contexts, summarize literature with page numbers and without a verdict, mark a possible same-graph relation as only suspected, or search whether a reading was proposed before. Do not, alone, merge graphs, restore broken text, assign a period or group, or write that a reading is settled.

### 2. Ten-minute sample

`OBD-000001` is fictional. Its catalog number is not a real publication. The drill file `pilot/_drill/OBD-900001.md` is not a result.

### 3. Pick one

Context entry, literature summary, or a prior-art search. Times on the Chinese table are rough.

### 4. Two independent entries

Do not read the other person’s file. Exact match after normalization counts as agreement. Conflicts are not merged automatically.

### 5. Review

The agreement rate is not accuracy and is not a scoreboard. It only feeds reviewer eligibility after three later matches. That count is empirical and not calibrated.

### 6. Conduct

No spam, no harassment, and no claim that an entry is a final decipherment.

### 7. Copyright

No images and no unlicensed text. Unencoded graphs need an id first.

### 8. Questions

Enable GitHub Discussions in the repository settings. This page names no external community.
